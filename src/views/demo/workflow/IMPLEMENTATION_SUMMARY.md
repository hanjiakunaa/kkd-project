## 🚀 使用指南

### 快速开始

#### 1. 使用 Vision 节点

```javascript
// 在工作流中添加 Vision 节点
{
  type: 'vision-node',
  params: {
    provider: 'openai',
    model: 'gpt-4o',
    prompt: '请详细描述这张图片',
    temperature: 0.7
  }
}

// 输入：图片 URL 或 Base64
// 输出：图片内容描述文本
```

#### 2. 使用 OCR 节点

```javascript
// 在工作流中添加 OCR 节点
{
  type: 'ocr-node',
  params: {
    provider: 'qwen',
    language: 'auto',
    outputFormat: 'text'
  }
}

// 输入：文档图片 URL
// 输出：识别的文字内容
```

#### 3. 使用模板

```javascript
// 从模板库加载
1. 点击"模板库"按钮
2. 选择"OCR 文档处理器"或"AI 图片智能分析"
3. 点击"使用模板"
4. 根据需要调整参数
5. 运行工作流
```

#### 4. 管理缓存

```javascript
// 查看缓存统计
const stats = await executor.getCacheStats()
console.log(stats)
// { totalCount: 45, memoryCount: 10, hitRate: '80%' }

// 清空缓存
await executor.clearCache()

// 禁用缓存
executor.disableCache()
```
