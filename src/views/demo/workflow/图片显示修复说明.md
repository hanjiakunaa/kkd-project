## ✅ 解决方案

### 修改执行引擎的格式化函数

**文件**：`src/views/demo/workflow/engine/executor.js`

**修改前** ❌：
```javascript
_formatOutputForDisplay(output) {
  if (typeof output === 'string') {
    return output
  }
  if (typeof output === 'object') {
    // ❌ 所有对象都转成JSON，导致图片无法显示
    return JSON.stringify(output, null, 2)
  }
  return String(output)
}
```

**问题**：
- ❌ 图片对象被转成JSON字符串
- ❌ 输出节点无法识别图片格式
- ❌ 用户看到的是JSON而不是图片

---

**修改后** ✅：
```javascript
_formatOutputForDisplay(output) {
  if (typeof output === 'string') {
    // 返回完整内容，不截断
    return output
  }
  if (typeof output === 'object') {
    // ✅ 如果是图片对象，返回markdown格式
    if (output.type === 'image' && output.markdown) {
      return output.markdown
    }
    // ✅ 如果是视频对象，返回markdown格式
    if (output.type === 'video' && output.markdown) {
      return output.markdown
    }
    // 其他对象返回完整的JSON字符串
    return JSON.stringify(output, null, 2)
  }
  return String(output)
}
```

**改进**：
- ✅ 检测图片对象类型
- ✅ 返回markdown格式字符串
- ✅ 同时支持视频对象
- ✅ 保持其他对象的JSON显示
