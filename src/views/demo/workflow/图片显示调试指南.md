## 🚨 可能的问题场景

### 场景1：API返回格式不对

**日志显示**：
```
[智谱AI] 图片生成API返回: undefined
或
[智谱AI] 图片生成API返回: null
或
[智谱AI] 图片生成API返回: {error: "..."}
```

**问题**：API调用失败或返回了错误

**解决方案**：
- 检查API Key是否正确
- 检查网络请求是否成功
- 查看Network标签的Response

---

### 场景2：URL提取失败

**日志显示**：
```
[智谱AI] 图片生成API返回: [{url: "https://..."}]
[智谱AI] 提取的图片URL: ""  ← 空字符串！
```

**问题**：URL提取逻辑有误

**解决方案**：检查API返回的确切格式

---

### 场景3：Markdown格式错误

**日志显示**：
```
[图片生成] Markdown格式: 山峦风景 (https://...)  ← 不是 ![](url) 格式
```

**问题**：Markdown格式化错误

**解决方案**：修复image-gen.js的markdown生成

---

### 场景4：格式化丢失

**日志显示**：
```
[格式化输出] 原始输出: {type: "image", url: "...", markdown: "![](...)"}
[格式化输出] 对象类型: undefined  ← 没有type字段！
或
[格式化输出] 是否有markdown: false  ← 没有markdown字段！
```

**问题**：对象结构不对

**解决方案**：修复executor返回格式

---

### 场景5：图片检测失败

**日志显示**：
```
[图片检测] 输出内容: "一些文本内容，不是markdown"
[图片检测] 是否匹配markdown图片: false  ← 没匹配上！
```

**问题**：输出不是markdown格式

**解决方案**：回溯到前面的步骤查找问题
