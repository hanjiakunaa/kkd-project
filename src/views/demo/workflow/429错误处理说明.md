## 📋 问题分析

### 429错误的原因

**1. 请求频率过高**
```
用户在短时间内发送了太多请求
超过了API的速率限制（Rate Limit）
```

**2. 智谱AI的限制**
```
免费账户：
- 每分钟：X次请求
- 每小时：Y次请求
- 每天：Z次请求

付费账户：
- 更高的限制
- 但仍有上限
```

**3. 常见触发场景**
- ❌ 快速连续点击运行
- ❌ 同时运行多个工作流
- ❌ 循环调用AI接口
- ❌ 多个标签页同时使用

#### 1️⃣ 图片生成 - 添加重试

**修改前** ❌：
```javascript
async generateImage(prompt, options = {}) {
  const url = `${this.baseUrl}/images/generations`
  const payload = {...}

  const response = await fetch(url, {...})

  // ❌ 直接抛出错误，不重试
  if (!response.ok) {
    const errorText = await response.text()
    throw new Error(`智谱 API 错误 ${response.status}: ${errorText}`)
  }

  const data = await response.json()
  return data.data?.[0]?.url || ''

```

**问题**：
- ❌ 遇到429直接失败
- ❌ 没有重试机制
- ❌ 用户体验差

---

**修改后** ✅：
```javascript
async generateImage(prompt, options = {}) {
  const url = `${this.baseUrl}/images/generations`
  const payload = {
    model: options.model || 'cogview-4',
    prompt,
    size: options.size || '1024x1024',
  }

  // ✅ 带重试的请求（处理429错误）
  const maxRetries = 3
  let lastError = null

  for (let i = 0; i < maxRetries; i++) {
    try {
      // ✅ 如果是重试，等待一段时间（指数退避）
      if (i > 0) {
        const delay = Math.min(1000 * (2 ** i), 10000) // 1s, 2s, 4s
        console.warn(`[智谱AI] 请求限流，${delay / 1000}秒后重试 (${i}/${maxRetries})...`)
        await new Promise(resolve => setTimeout(resolve, delay))
      }

      const response = await fetch(url, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'Authorization': `Bearer ${this.apiKey}`,
        },
        body: JSON.stringify(payload),
      })

      // ✅ 429 Too Many Requests - 继续重试
      if (response.status === 429) {
        const errorText = await response.text()
        lastError = new Error(`请求频率超限，请稍后重试`)
        console.warn(`[智谱AI] 429错误: ${errorText}`)
        continue // 继续下一次重试
      }

      // ✅ 其他错误 - 直接抛出（不重试）
      if (!response.ok) {
        const errorText = await response.text()
        throw new Error(`智谱 API 错误 ${response.status}: ${errorText}`)
      }

      // ✅ 成功
      const data = await response.json()
      return data.data?.[0]?.url || ''
    }
    catch (error) {
      // 如果是最后一次重试，抛出错误
      if (i === maxRetries - 1) {
        throw lastError || error
      }
      lastError = error
    }
  }

  throw lastError || new Error('图片生成失败')
}
```

**改进**：
- ✅ 遇到429自动重试
- ✅ 指数退避等待
- ✅ 友好的控制台提示
- ✅ 最多重试3次

#### 2️⃣ Chat对话 - 同样添加重试

```javascript
async chat(messages, options = {}) {
  const url = `${this.baseUrl}/chat/completions`
  const payload = {...}

  // ✅ 同样的重试逻辑
  const maxRetries = 3
  let lastError = null

  for (let i = 0; i < maxRetries; i++) {
    try {
      if (i > 0) {
        const delay = Math.min(1000 * (2 ** i), 10000)
        console.warn(`[智谱AI] 请求限流，${delay / 1000}秒后重试 (${i}/${maxRetries})...`)
        await new Promise(resolve => setTimeout(resolve, delay))
      }

      const response = await fetch(url, {...})

      if (response.status === 429) {
        lastError = new Error(`请求频率超限，请稍后重试`)
        continue
      }

      if (!response.ok) {
        const errorText = await response.text()
        throw new Error(`智谱 API 错误 ${response.status}: ${errorText}`)
      }

      const data = await response.json()
      return data.choices?.[0]?.message?.content || ''
    }
    catch (error) {
      if (i === maxRetries - 1) {
        throw lastError || error
      }
      lastError = error
    }
  }

  throw lastError || new Error('对话生成失败')
}
```

## 🎯 重试策略详解

### 指数退避算法

**公式**：`delay = Math.min(1000 * (2 ** retryCount), 10000)`

**重试时间表**：

| 重试次数 | 等待时间 | 计算公式 | 累计时间 |
|---------|---------|---------|---------|
| 第1次 | 0秒 | - | 0秒 |
| 第2次 | 1秒 | 1000 * 2^0 | 1秒 |
| 第3次 | 2秒 | 1000 * 2^1 | 3秒 |
| 第4次 | 4秒 | 1000 * 2^2 | 7秒 |

**最大等待时间**：10秒（避免等待太久）
