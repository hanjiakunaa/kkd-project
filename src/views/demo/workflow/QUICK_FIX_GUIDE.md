## 🔧 如果还是报错

### 检查 1：API Key 是否正确

```javascript
// 打开浏览器控制台（F12），执行：
localStorage.getItem('wf_api_key_openai')

// 应该返回你的 API Key
// 如果返回 null，说明没保存成功，重新配置
```

### 检查 2：服务商是否匹配

确保模板中的节点使用的服务商，你已经配置了对应的 API Key。

**例如**：
- 模板使用 OpenAI → 配置 OpenAI 的 Key
- 模板使用智谱 AI → 配置智谱的 Key

### 检查 3：API Key 是否有效

1. API Key 格式正确（通常以 `sk-` 开头）
2. API Key 未过期
3. 账户有余额（国内服务商）

### 检查 4：网络是否通畅

- **OpenAI**：可能需要科学上网
- **国内服务商**（智谱、通义、DeepSeek）：直连即可
