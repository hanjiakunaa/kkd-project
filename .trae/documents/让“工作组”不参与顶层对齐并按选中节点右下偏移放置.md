## 目标
- 新增工作组时，位置精确在当前选中顶层节点的右下（不与其他顶层节点对齐到同一水平线）。
- 顶层自动对齐不影响工作组；仅普通顶层节点保持线性对齐。

## 修改点（仅改动 index.vue）
1) 更新 addNode 定位逻辑
- 位置：`src/views/demo/workflow/index.vue` 的 `addNode(type)`
- 变更：
  - 选择参考节点：当前选中的“顶层节点”（`!parentNode`），否则链尾。
  - 若 `type==='group-node'`：`pos = { x: candidate.position.x + 240, y: candidate.position.y + 80 }`
  - 若为普通节点：保持现有 `{ x:+260, y:+0 }`
  - `nextTick(() => requestAnimationFrame(() => vueFlowInstance.fitView()))`

2) 更新 alignLinear（跳过工作组）
- 位置：`function alignLinear()`（约 560 行附近）
- 变更：
  - `starts`：`nodes.value.filter(n => n.data.type === 'input-node' && !n.parentNode)`（已存在）
  - 构建 `order`：过滤掉工作组与组内节点：
    - `nodes.value.filter(n => !visited.has(n.id) && !n.parentNode && n.data.type !== 'group-node')`
  - 最终定位：仅对 `!n.parentNode && n.data.type !== 'group-node'` 的节点设置 `n.position`

## 验证
- 选中某个顶层节点 → 点击“工作组”，新组出现在该节点右下偏移位置；后续顶层对齐不会把它拉回一条线。
- 顶层普通节点仍线性对齐；组内添加与边连线保持可见。
