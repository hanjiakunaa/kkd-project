## 现状评估
- 当前使用 Naive UI 的 `n-upload`，仅触发 `on-change` 读取文件并用 `FileReader` 转为 DataURL；Fabric 以本地 DataURL 加载图片，无后端依赖。
- 你截图中的 Supabase 400 是浏览器扩展触发的网络请求，与该页面代码无关。

## 调整目标
- 明确保证“零后端”与“零网络请求”：不设置 `action`、不使用 `custom-request`、不调用 axios/fetch。
- 所有展示与标注在浏览器内存完成；导出 JSON/PNG 直接本地生成 Blob 下载。

## 具体改动
1. 上传拦截（前端校验）：
   - 增加 `on-before-upload` 限制文件类型、大小（例如 ≤ 20MB），失败直接在前端提示。
   - 继续使用 `on-change` + `FileReader.readAsDataURL`，确保本地数据流。
2. Fabric 加载方式：
   - 使用 `Image.fromURL(dataUrl)`，移除不必要的 `crossOrigin` 配置（DataURL 不需要）。
3. 可视化反馈：
   - 上传后显示文件名、原始尺寸、缩放百分比；空状态保持本地提示。
4. 导出/导入（本地）：
   - 保留“导出 JSON/PNG”本地下载；新增“导入 JSON”从本地选择文件同步标注。

## 验证
- 打开浏览器 Network 面板：上传/标注/导出全程无网络请求（仅 blob/url 访问）。
- 大图本地加载与矩形标注、视图拖拽/缩放正常。
